=====================================================================
 TOOLS GUIDE - CARDS OF DECEPTION
=====================================================================

1. สร้างปุ่มเข้าเกมบนหน้าจอ_Desktop.bat
   - สร้างทางลัด (Shortcut) เข้าเกมบนหน้าจอ Desktop พร้อมไอคอนเกม

2. หยุดเซิร์ฟเวอร์.bat
   - สั่งปิด Server ที่กำลังทำงานอยู่บนพอร์ต 3000 ทันที

3. เปิด_Server_อัตโนมัติตอนเปิดคอม.bat
   - ตั้งค่าให้เซิร์ฟเวอร์ทำงานอัตโนมัติเมื่อเปิดเครื่องคอมพิวเตอร์ (รันแบบซ่อนหน้าต่าง)

4. ยกเลิกเปิด_Server_ตอนเปิดคอม.bat
   - ยกเลิกการเปิดเซิร์ฟเวอร์อัตโนมัติตอนเปิดเครื่อง

5. เริ่มเล่นเกม_แบบซ่อนหน้าต่าง.vbs
   - สคริปต์รันเซิร์ฟเวอร์เบื้องหลังโดยไม่แสดงหน้าต่างจอดำ (Hidden Window)

6. สแกนหาเครื่องในวงแลน.bat
   - สแกนหา IP และชื่อเครื่องของเพื่อนในวงแลน/Wi-Fi เดียวกัน เพื่อแชร์ลิงก์เข้าเล่นเกม
=====================================================================
